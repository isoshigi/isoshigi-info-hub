## Detector

</SlideCard>

<SlideCard slideTitle={frontmatter.title}>

全呼称の全表記から1つの巨大正規表現にコンパイル

**長い文字列優先** + 重複マッチ除外

</SlideCard>

<SlideCard slideTitle={frontmatter.title}>

```ruby
# 全呼称の全表記から正規表現を生成
# 長い文字列を優先することで重複マッチを防ぐ
def build_regex(forms)
  sorted = forms.sort_by(&:length).reverse
  escaped = sorted.map { |f| Regexp.escape(f) }
  Regexp.new(escaped.join('|'), Regexp::IGNORECASE)
end
```

</SlideCard>

<SlideCard slideTitle={frontmatter.title}>

```ruby
# テキストから呼称を検出し、位置と種類を特定
detector = Imagawayaki.detector
matches = detector.detect('人工衛星饅頭とベイクドモチョチョ')
matches.map { |m| [m.matched_text, m.name.key] }
# => [["人工衛星饅頭", :jinkoueiseimanjuu],
#     ["ベイクドモチョチョ", :bakedmochocho]]
```
