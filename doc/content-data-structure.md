# Content Data Structure

本ドキュメントは、「いそしぎ忘備録」で扱うコンテンツのデータ構造を定義する。
すべてのコンテンツは共通スキーマに従い、本文（MDX）を持つ。

## 共通スキーマ（Common Schema）

全コンテンツタイプで共通して使用するメタデータフィールド。

| フィールド名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `title` | string | Yes | コンテンツのタイトル。SEO・OGP・一覧表示に使用。 |
| `description` | string | Yes | コンテンツの概要。SEO・OGP・一覧表示に使用。最大200文字程度を推奨。 |
| `publishedAt` | ISO 8601 Date | Yes | 公開日。ソートやフィード生成に使用。 |
| `updatedAt` | ISO 8601 Date | No | 更新日。未指定の場合は `publishedAt` と同値とみなす。 |
| `tags` | string[] | No | コンテンツを分類するタグ。一覧フィルタや関連コンテンツ表示に使用。 |
| `draft` | boolean | No | `true` の場合、ビルド時に公開対象から除外する。デフォルトは `false`。 |
| `coverImage` | string | No | カード一覧（`SummaryCard`）表示用の画像パス。**OGP画像はビルド時に自動生成されるため、`coverImage` はOGPには使用されない。** |

> **メタデータの表示方針**: すべてのメタデータフィールドは「一覧表示用」「詳細表示用」に分けず、共通の概要パネルに表示する。詳細ページの上部にも概要パネルを配置し、メタデータを重複して表示する。

## 記事（Article）

- **配置ディレクトリ**: `src/content/articles/`
- **ファイル形式**: `.mdx`
- **ファイル命名**: `slug.mdx`（URLパスに使用されるスラッグ）
- **スキーマ**: 共通スキーマ（拡張なし）
- **詳細ページ**: `/articles/[slug]` — 概要パネル + MDX本文

## スライド（Slide）

- **配置ディレクトリ**: `src/content/slides/`
- **ファイル形式**: `.mdx`
- **ファイル命名**: `slug.mdx`（URLパスに使用されるスラッグ）
- **スキーマ**: 共通スキーマ + `theme?`（string）
- **本文**: `<Slide>` コンポーネントでラップされた prose コンテンツ。各スライドは aspect-video カードとしてスライドビューア内にレンダリングされる。
- **詳細ページ**: `/slides/[slug]` — 概要パネル + スライドビューア

## ストーリー（Story）

一連の流れのあるコンテンツ群と、その背景情報を持つコンテンツ。詳細ページでは、`storyFlow` に含まれる各参照先を `SummaryCard` リンクとして縦に並べ、その下に本文（MDX）を配置する。

| フィールド名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `storyFlow` | `{ collection: 'articles' \| 'slides' \| 'stories', slug: string }[]` | Yes | ストーリーに関連する他コンテンツへの参照リスト。各要素は対象コレクションとスラッグでコンテンツを指定する。詳細ページでは各参照先が `SummaryCard` としてリンク表示される。表示タイトルは参照先コンテンツの `title` が使用される。 |

- **配置ディレクトリ**: `src/content/stories/`
- **ファイル形式**: `.mdx`
- **ファイル命名**: `slug.mdx`（URLパスに使用されるスラッグ）
- **詳細ページ**: `/stories/[slug]` — 概要パネル + ストーリー流れ + MDX本文

## 調べ物（Scrap）

散文形式のノートを蓄積するコンテンツ。検証結果や試行記録などの生のログを、軽量なエントリ群としてまとめて公開する。

- **配置ディレクトリ**: `src/content/scraps/`
- **ファイル形式**: `.mdx`
- **ファイル命名**: `slug.mdx`（URLパスに使用されるスラッグ）
- **スキーマ**: 共通スキーマ（拡張なし）
- **本文**: `<ScrapEntry>` コンポーネントでラップされた prose コンテンツ。各エントリにはオプションの `type` prop（`'note'` | `'quote'` | `'code'` | `'link'`）を指定でき、見た目が切り替わる。スライドと異なりサイズ制約はない。
- **詳細ページ**: `/scraps/[slug]` — 概要パネル + MDX本文

## バリデーションルール

1. **必須フィールド欠如**: 必須フィールドが欠落している場合、ビルド時に警告またはエラーを出力する。
2. **無効な日付形式**: `publishedAt`, `updatedAt` が ISO 8601 Date でない場合、ビルド時にエラーを出力する。
3. **不正なタグ**: `tags` に空文字列や重複値が含まれる場合、ビルド時に警告を出力し、空文字列を除外・重複を除去して処理する。
