# Page Structure

本ドキュメントは、いそしぎ忘備録の画面構成とURLルーティングを定義する。

## 全ページ共通レイアウト

すべてのページで以下のレイアウトを共有する。

- **ヘッダー**: サイトタイトル、グローバルナビゲーション（`/`、`/pages`）
- **フッター**: 著作権表示、SNSリンクなど
- **サイドバー**: （v0.1 では最小限の内容。将来の拡張を見据えてレイアウトのみ確保）

## URL ルーティングとページ役割

| URL | ページ名 | 役割 | 備考 |
|---|---|---|---|
| `/` | トップページ | 最新のコンテンツ数件、プロフィール、サイト概要への導線を表示する。 | v0.1 |
| `/pages` | 全コンテンツ共通一覧 | 記事・スライド・ストーリー・調べ物を時系列で混在して一覧表示する。各アイテムは概要パネルで表示する。 | v0.1 |
| `/articles/[slug]` | 記事詳細 | 概要パネル + MDX本文を表示する。 | v0.1 |
| `/slides/[slug]` | スライド詳細 | 概要パネル + スライドビューアを表示する。 | v0.3 |
| `/stories/[slug]` | ストーリー詳細 | 概要パネル + ストーリー本文を表示する。 | v0.3 |
| `/scraps/[slug]` | 調べ物詳細 | 概要パネル + MDX本文を表示する。 | v0.4 |

## ページ構成のルール

1. **全コンテンツの統合一覧**: すべてのコンテンツタイプ（記事・スライド・ストーリー・調べ物）を `/pages` に集約し、時系列で混在表示する。種別は SummaryCard のバッジで視覚的に区別する。
2. **概要パネルの配置**:
   - 共通一覧（`/pages`）: 各アイテムを概要パネル（カード形式）で表示
   - 詳細ページ（`/articles/[slug]`、`/slides/[slug]`、`/stories/[slug]`、`/scraps/[slug]`）: ページトップに概要パネルを配置し、その下にコンテンツ本体を表示
3. **SEO メタ情報**: すべてのページで `<title>`、`<meta name="description">`、OGP 画像を設定する。詳細ページはコンテンツ個別のメタ情報を使用する。**OGP 画像はビルド時に自動生成される（`/img/.../og.png`）。**
